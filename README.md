# 时光年龄 PWA

基于桌面版“年龄计算器”的计算规则制作的手机网页应用。支持公历、农历与闰月出生日期，显示周岁、虚岁、精确年龄、生肖星座、干支、公农历生日倒计时和目标年龄进度。所有计算在浏览器本地完成，首次打开后可离线使用。

选好生日和时光目标后，点击“设为默认生日”，下次打开会自动载入并计算。可以随时修改日期；要更新默认值，再点击“设为默认生日”。“取消默认”会删除保存的设置。默认生日只保存在当前设备的网站存储中，不上传服务器；清除网站数据后需要重新设置，不同设备或浏览器需各自设置。

有默认生日时，首页直接显示年龄和生日倒计时。“修改生日”展开表单；修改日期后会隐藏旧结果并提示更新，“取消修改”恢复此前的档案。可以在“保存生日档案”中填写名称并保存最多 20 个本地档案，之后用首页下拉框切换；切换和临时计算不会覆盖默认生日。若某档案被设为默认，保存该档案的修改会同步更新默认设置，删除该档案也会取消关联的默认设置。

生日当天会显示祝福，同时保留下一次生日倒计时。页面跨过本地午夜或返回前台后，会更新日期与结果；正在编辑的生日会保留。页底显示离线准备状态及新版本提示，新版准备好后点击“更新应用”加载。

## 本地运行

在本目录运行：

```powershell
python -m http.server 4173
```

电脑浏览器打开 `http://localhost:4173/`。不要直接双击 `index.html`：浏览器对本地文件的模块加载和 PWA 缓存有限制。

## iPhone 安装

将本目录的静态文件部署到支持 HTTPS 的网站，再用 iPhone Safari 打开。点击 Safari 的“分享”按钮，选择“添加到主屏幕”。首次在线打开并完成缓存后，可以断网使用。仅在本机电脑启动的 `localhost` 地址无法从 iPhone 直接访问，也不能代替 HTTPS 部署。

## 计算口径

- 日期范围：公历 1900-01-31 至 2100-12-30；农历年 1900–2100。
- 2 月 29 日生日在非闰年按 2 月 28 日计算。
- 农历闰月生日遇到无对应闰月时，按同名普通月计算；月份天数不足时按月末计算。
- 下一次生日严格晚于今天，生日当天展示下一年。
- 虚岁按当前与出生农历年计算。时光进度为整数周岁除以用户设置的目标年龄。
- 日期取设备的本地日期。页面跨过午夜或返回应用时若已跨日，结果会重新计算；待更新的生日表单保留到用户确认。
- 干支按节气所在日期切换，不区分出生时辰。1900 年节气使用原桌面版的近似算法。
- 1901–2100 年农历月初和节气数据来自原项目保存的[香港天文台公农历对照表](https://www.hko.gov.hk/tc/gts/time/conversion.htm)；月初已与其 2474 条记录逐条核对。

## 开发与验证

```powershell
npm test
```

2026-09-23 的计算核验：1,060 个不同生日、4,209 组生日与计算日期，年龄、农历、生日倒计时及干支等结果与原 Python 版一致；香港天文台参考历表覆盖的 73,029 个公历日期均通过公农历双向换算。1900 年及 1901 年初的日期与原版逐日对照，1900 年尚无同等独立的天文台历表核验。

`calendar-data.js` 已包含运行需要的离线数据。原桌面项目路径及生成脚本留在本机，不包含在公开站点中。
